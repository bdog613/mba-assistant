# Corrections Log

Append-only memory of your feedback. **Read this at the start of every run** (Phase 0) and apply every rule below to the new deliverable. This is how the skill compounds: each correction becomes a permanent rule so the same mistake is never repeated.

## Format
One rule per bullet. Date it. Keep it short and imperative. If a rule later turns out to be wrong or too broad, strike it through (`~~like this~~`) with a note rather than deleting, so the history stays honest.

`- YYYY-MM-DD, <the rule, as an instruction>. (context: <which assignment / why>)`
